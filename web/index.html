1. Провайдер ИИ

Работает с любым OpenAI-совместимым эндпоинтом (OpenAI, DeepSeek, GLM/Z.AI, Groq, OpenRouter, Moonshot, Ollama, LM Studio, vLLM) и с Anthropic API. Провайдеры из конфига opencode подтягиваются автоматически — можно добавить свой ключ.

2. Резюме

Поддерживаются PDF, DOCX, TXT, HTML и вставка текстом. ИИ разберёт резюме в профиль: навыки, стек, ставку, пожелания и «что точно не хочу».

3. Профиль исполнителя

Проверь и поправь — на этом профиле строится подбор заказов.

4. Подбор заказов

ИИ оценит заказы из текущей ленты по твоему профилю и объяснит, что брать.
