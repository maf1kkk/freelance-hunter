# Безопасность

## Никогда не коммитьте секреты

Всё, что содержит учётные данные, лежит в `data/` и `output/` — обе папки в `.gitignore`:

| Файл | Что внутри |
|---|---|
| `data/session.json` | сессия alot.pro (UID + S) |
| `data/accounts.json` | импортированные cookie-файлы площадок |
| `data/ai-providers.json` | API-ключи ИИ-провайдеров |
| `data/store.db` | вся лента заказов и твои профили |
| `data/profiles/` | профили браузера для автоотклика |
| `output/` | скриншоты и сгенерированные карточки |

Перед публикацией форка проверьте `git status` — в индексе не должно быть ничего из `data/`.

## Что делать, если утекли ключи

1. **alot.pro** — выйдите из аккаунта на всех устройствах, смените пароль, заново выполните `npm run login`.
2. **Cookie-файлы площадок** — выйдите из аккаунтов на fl.ru / kwork.ru / hh.ru и войдите заново; старые сессии станут недействительны.
3. **Ключи ИИ-провайдеров** — отзовите ключ в панели провайдера (OpenRouter / Z.AI / DeepSeek / …) и создайте новый.

## Ответственное использование

Инструмент ходит на сайты бирж с разумной частотой (пауза между запросами к одному хосту — 350 мс).
Не меняйте это значение на 0 и не запускайте массовый опрос в несколько процессов: агрессивный опрос
может привести к блокировке вашего IP или аккаунта на стороне площадки.

## Уязвимости

Нашли проблему — создайте issue или напишите приватно мейнтейнеру. Не публикуйте
эксплойт до выхода исправления.
